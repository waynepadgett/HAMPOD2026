ICOMReader :
v2.06b1
Added ability to toggle Data Mode on/off on applicable radios
Will only set Data Mode D1 on IC-7610 and IC-7851. 
v2.06
Fixed several issues with IC-9700 including clock, memory access, DStar, and quick band change functions
Added command to select Main or Sub receiver for IC-7800/7851/9100/9700
Added a debug mode to help with testing

v2.05b42
Added Quick Band Change function for 9700
Set SWR power level to 15 watts or 50% on IC-703

v1.05 b41
Added ability to set and clear VFO and front panel locks

v1.05 b40
Fixed Tuning Step values for IC-9700
Fixed memory channel alpha tag length to 16 characters for IC-9700. 

v1.05 b38
Added preliminary support for IC-910(H)

v1.05 b37
Fixed addressing for future large memory firmware builds.
 
v1.05 b36b2
When stopping Memory Scan, now auto copies Mem Channel data to VFO

v1.05 
Added set Duplex Offset frequency function
Combined Split (On/Disable), onto one toggle key
Combined Duplex Direction (Minus/Plus/Disable), onto one toggle key
Added Scan function for current memory bank on supported models.
Added new query for Antenna Tuner status (Disabled, On, Tuning). [7], Hold. 
Added new memory mode 2: automatic memory channel data to VFO transfer [Shift] , [C] Hold
Added read/set RF/Squelch Control setting
Added support for IC-746 (non Pro)
Added ability within SWR query to hold in transmit until a key is pressed to continue. Used to wait for external antenna tuner to complete tuning. 
Added DStar Mode support for IC-7100 and IC-9100.
	Added ability to create an alpha name and assign to a memory channel
	Fixed Text-To-Speech input buffer overrun error

Added support for new IC-7610
Added Voltage and Current query for IC-7610
Added "Set" function for VOX Delay
Added "Set" function for PreAmp 1 and 2
Added "Set" function for AGC Speed and Level
Added "Set" function for Attenuation on/off and level if applicable
Added DTMF Tone Duration configuration option
Restructured Notch query code and added Notch filter Width query
				Added "Set" function for Notch filter settings
